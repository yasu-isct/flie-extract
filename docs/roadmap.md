# Roadmap

See also: [Product Mainline](product_mainline.md)

## Retrieval and Reasoning

- Add a lightweight document graph for sections, anchors, internal references, and applicability conditions.
- Extend recursive retrieval beyond direct references, including section-neighbor expansion and condition-driven follow-up retrieval.
- Add target-aware locality scoring so target program terms and exam/document terms must appear in the same page or section window.
- Add a reasoning-chain layer based on questions, evidence, conclusions, source pages, and uncertainty.
- Add document-level base extraction so multiple profiles can reuse the same university/program knowledge base.
